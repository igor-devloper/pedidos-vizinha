# Fotos para tirar (Vizinha Salgateria)

As fotos não são obrigatórias: sem elas o site mostra um quadro colorido no lugar. Mas com foto real fica muito melhor.
Coloque os arquivos em `public/fotos/` com o nome exato abaixo (formato `.jpg`). Quando o arquivo existe, a foto aparece sozinha.

## Como fotografar
- **Luz natural de janela**, de dia. Nada de flash.
- **Fundo neutro**: bandeja de madeira, tábua ou toalha de mesa lisa.
- **De perto**, com a câmera na altura do salgado (ou de cima, bem reta).
- Em cada sabor, **um salgado aberto ao meio mostrando o recheio**, ao lado de alguns inteiros.
- Celular na horizontal. Limpe a lente antes. Evite filtros.

## Lista

| Arquivo | O que fotografar |
|---|---|
| `vizinha-cozinha.jpg` | A Vizinha na cozinha, sorrindo, com uma bandeja de salgados. |
| `bandeja-festa.jpg` | Mesa de festa com os salgados variados (foto grande do topo do site). |
| `coxinha.jpg` / `coxinha-de-frango.jpg` | Coxinhas, uma aberta mostrando o recheio. |
| `bolinha-de-queijo.jpg` | Bolinhas de queijo, uma partida ao meio. |
| `pastel-frito.jpg` | Pastéis fritos, um aberto. |
| `pastel-frito-acucarado.jpg` | Pastéis açucarados. |
| `pastel-de-carne.jpg` / `pastel-de-carne-acucarado.jpg` | Pastel de carne (salgado e açucarado). |
| `risole-misto.jpg` | Risoles, um aberto. |
| `churros.jpg` | Churros com a cobertura que usa. |

O nome do arquivo de cada sabor é o nome do sabor em minúsculas, sem acento, com hífen no lugar do espaço
(ex.: "Pastel frito açucarado" vira `pastel-frito-acucarado.jpg`). Os sabores vêm do cadastro de cada produto no painel.

## Antes de subir
Reduza cada foto para até 1600 px de largura e menos de 400 KB (por exemplo em squoosh.app, formato JPG).
